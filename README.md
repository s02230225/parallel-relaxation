# Параллельная релаксация двумерной сетки

**C · OpenMP · MPI**

Сравнение способов исполнения итерационного обновления двумерной сетки: последовательный вариант, OpenMP с обходом по диагоналям, конвейерная организация OpenMP и распределённая обработка MPI с halo-областями.

```bash
make
make mpi
./sequential 16
./openmp_for 2 16 1
./openmp_pipeline 2 16 1
mpirun -np 2 ./mpi 16
```

Сетка имеет нулевые граничные значения. Внутри обновление использует веса 2 для верхнего и левого соседей и 1 для нижнего и правого, с делением на 6. Волновой порядок сохраняет зависимости обновлений. Число процессов MPI не должно превышать число внутренних строк N−2.

Вывод CSV: число потоков/процессов, время, размер сетки, контрольная сумма, вариант. Для последовательного примера время измеряется процессорными часами, для OpenMP/MPI — настенными; для количественного бенчмарка следует выбрать единую методику.

Для сборки нужны C11, OpenMP и, для MPI-варианта, реализация MPI с mpicc/mpirun. Начать удобно с N=8 или N=16, сверяя контрольные суммы.
